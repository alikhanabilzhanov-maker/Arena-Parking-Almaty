# Кері байланыс ережелері

- Көрермен тұрақ қызметі туралы пікір немесе шағым жібереді.
- Өтініштің бастапқы статусы — «Жаңа».
- Іс-шара менеджері өтінішті қарап, «Қаралуда» статусын қояды.
- Менеджер жауап бергеннен кейін статус «Жауап берілді» болып өзгереді.
- Көрермен өз өтінішінің статусын және жауабын көре алады.
