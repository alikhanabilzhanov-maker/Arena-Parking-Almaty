# Use Case

## UC01 Аймақ брондау
Actor: Көрермен
Бастапқы шарт: Көрермен кірген, іс-шара мен аймақтар дайын тест деректерімен енгізілген.
1. Іс-шараны таңдап, билет нөмірі, сектор және көлік нөмірін енгізеді.
2. Жүйе тест тізіміндегі билет пен таңдалған секторды салыстырады.
3. Жүйе сәйкестік кестесінен жақын ашық аймақты көрсетеді.
4. Көрермен аймақты таңдайды.
5. Жүйе резерв пен расталған броньдарды ескеріп, бос қорды тексереді.
6. Орын бар болса, Төлем күтілуде бронін сақтайды.
Балама: Билет табылмаса қате хабарламасы беріледі. Аймақ толса басқа сәйкес аймақ ұсынылады немесе брондау тоқтайды.
Нәтиже: Аймақтан бір орын резервке алынады; нақты орын нөмірі жоқ.

## UC02 Төлемді растау
Actor: Көрермен
Бастапқы шарт: Төлем күтілуде броні бар.
1. Көрермен оқу төлемін бастайды.
2. Сынақ нәтижесі Сәтті немесе Сәтсіз ретінде беріледі.
3. Жүйе төлем жазбасын сақтайды.
4. Сәтті болса броньды Расталды деп өзгертіп, кіру кодын береді.
Балама: Сәтсіз төлемде бронь Бас тартылды болады және резерв босайды. Қайта әрекет жаңа броньмен жасалады. Қайталанған нәтиже екінші растау жасамайды.
Нәтиже: Расталған бронь мен кіру коды бар немесе резерв босатылған.

## UC03 Аймаққа кіру
Actor: Қауіпсіздік қызметкері
Бастапқы шарт: Көрермен дұрыс аймақтың кіреберісіне келген және расталған коды бар.
1. Қызметкер бронь кодын енгізеді.
2. Жүйе кодты, іс-шараны, аймақты және Расталды статусын тексереді.
3. Қызметкер көлік нөмірін броньмен салыстырады.
4. Жүйе статусын Кірді деп өзгертіп, кіру уақытын сақтайды.
5. Жүргізуші сол аймақтағы белгіленген бос тұрақ орнына көлігін қояды.
Балама: Қате, қолданылған код немесе басқа аймақ болса кіру қабылданбайды. Жүйе операторға тексеруге жібереді.
Нәтиже: Аймаққа кіру тіркелген; нақты орын тағайындалмайды.
