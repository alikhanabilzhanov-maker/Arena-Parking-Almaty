# Алматы стадионының тұрақ аймағын брондау

Ұсынылатын оқу жобасы.

Іс-шара + билет секторы → дайын кестеден аймақ → қор тексеру → бронь → оқу төлемі → кіру коды → қызметкер тексеруі.

Нақты орын нөмірі, уақыт интервалы және датчик жоқ. QR кейінгі кеңейту.

## Рөлдер
- Көрермен: Іс-шараны таңдайды, билет нөмірі мен секторын енгізеді, ұсынылған аймақты брондайды, төлем жасайды және өтініш жібереді.
- Паркинг операторы: Аймақ сыйымдылығы мен ашық немесе жабық статусын басқарады, бронь тізімін қарайды.
- Қауіпсіздік қызметкері: Бронь кодын тексереді, дұрыс аймаққа кіру мен шығуды тіркейді.
- Іс-шара менеджері: Іс-шара мен сектор–аймақ сәйкестігін енгізеді, бронь есебін қарайды, кері байланысқа жауап береді.
- Әкімші: Пайдаланушыларды және олардың бес рөлінің құқықтарын басқарады.
